# 친구 초대 (INVITE)

보안 설계는 `SECURITY.md`, 데이터 구조는 `DATA_MODEL.md` 참고.

## 흐름

```
방장: 방 만들기 → 대기실 → [초대 링크 만들기] → 공유하기 / 복사
친구: 링크 열기 → (인앱 브라우저면) 기본 브라우저로 이동 → 닉네임·동물 선택 → 참가하기 → 대기실
방장: 게임 시작 → 모두 미션 화면으로 이동
```

- 링크 형식: `https://{도메인}/invite/{방ID}/{초대코드}`
- 초대 코드는 영숫자 24자이고, 방장만 만들고 조회하고 폐기할 수 있다.
- 유효 시간은 24시간이다. 새 링크를 만들면 이전 링크는 모두 폐기된다.
- 방이 `waiting`(대기) 상태일 때만 참가할 수 있다. 게임이 시작되면 같은 링크로도 참가할 수 없다.
- 이미 참가한 사람이 링크를 다시 열면 대기실로 이동한다.

## 외부 브라우저로 열기

카카오톡 안에서 링크를 누르면 카카오톡의 인앱 브라우저로 열린다. 인앱 브라우저는 각 앱이 만든 기능이라 **외부로 나가는 공식 방법이 없다.** 그래서 초대 페이지가 인앱 브라우저를 감지해 아래 방법으로 기본 브라우저를 열도록 시도한다. 구현은 `apps/web/src/lib/invite/inAppBrowser.ts`.

| 열린 곳 | 방법 | 동작 |
|---|---|---|
| 카카오톡 (iOS, 안드로이드) | `kakaotalk://web/openExternal?url=...` 로 이동 | 기본 브라우저로 열림 (비공식 방법) |
| 라인 | 주소에 `openExternalBrowser=1` 추가 | 외부 브라우저로 열림 |
| 안드로이드의 그 밖의 인앱 브라우저 (네이버, 인스타그램, 페이스북, 다음) | `intent://` 주소로 이동 | 기본 브라우저로 열림 (기기에 따라 선택 창이 뜰 수 있음) |
| iOS의 그 밖의 인앱 브라우저 | 자동으로 나갈 방법 없음 | 안내 문구와 링크 복사 버튼 표시 |

자동 이동은 한 번만 시도하고(무한 반복 방지), 실패하면 화면에 **기본 브라우저로 열기** 버튼, 직접 여는 방법 안내, **링크 복사**가 남는다. 인앱 브라우저에서는 참가 입력을 받지 않고 기본 브라우저로 가도록 안내만 한다.

### 한계 (중요)

- 카카오톡의 `openExternal` 스킴은 카카오가 공식 문서화한 기능이 아니다. 개발자들이 널리 쓰지만, 이 스킴을 호출해도 인앱 브라우저에 남는다는 문의가 카카오 개발자 포럼에 올라온 적이 있고, 앱 업데이트로 동작이 달라질 수 있다.
- iOS의 인스타그램, 페이스북, 네이버 앱 등은 외부로 자동 이동할 수 없다. 사용자가 메뉴에서 직접 열어야 한다.
- 인앱 브라우저 감지는 User-Agent 문자열에 의존하므로 앱 업데이트로 어긋날 수 있다.
- 이 동작은 **실제 휴대폰에서 직접 확인하기 전에는 보장할 수 없다.** 아래 "실기기 테스트"를 따른다.

## 실기기 테스트

`localhost` 링크는 휴대폰에서 열리지 않으므로 인터넷에 배포된 HTTPS 주소(예: Vercel 미리보기)가 필요하다.

1. 배포한 도메인을 Firebase 콘솔 Authentication → 설정 → 승인된 도메인에 추가한다.
2. `cors.json`의 `origin`에 배포 주소를 추가하고 버킷에 다시 적용한다. (`FIREBASE_SETUP.md` 5번)
3. 방장 기기에서 방을 만들고 초대 링크를 만든다.
4. 링크를 **카카오톡 나와의 채팅**으로 보낸 뒤 눌러 본다.

| 확인 | 기대 결과 |
|---|---|
| 아이폰 카카오톡에서 링크 클릭 | 사파리(기본 브라우저)로 열림 |
| 갤럭시 카카오톡에서 링크 클릭 | 기본 브라우저(크롬, 삼성 인터넷 등)로 열림 |
| 자동 이동이 안 될 때 | 화면의 버튼이나 안내로 직접 열 수 있음 |
| 인스타그램 DM(iOS)에서 링크 클릭 | 안내 문구가 보이고 링크 복사가 됨 |
| 기본 브라우저에서 참가 | 닉네임 입력 → 참가 → 대기실에 내가 보임, 방장 화면에도 실시간으로 보임 |
| 같은 링크를 다시 열기 | 대기실로 바로 이동 |
| 새 링크를 만든 뒤 예전 링크 열기 | 참가 실패 안내 |
| 게임 시작 후 링크 열기 | 참가 실패 안내 |
